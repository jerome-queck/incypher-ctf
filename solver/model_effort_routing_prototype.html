The governor never knows an exact number of Turns left. It combines OpenAI's broad Pro 20x planning ranges, live window telemetry when available, and local per-workload measurements. Its objective changes by role, phase, difficulty and fault impact.

What the four roles actually mean

Triage JudgeOne adaptive batched judge for newly seen ambiguous Challenges. At Run start it protects startup latency; later it runs only for a new ambiguous release batch. Stated difficulty or qualified crowd evidence can eliminate the call.
Solve LeadThe generalist carried by one persistent thread inside an Attempt. Its model stays fixed for that Attempt; effort may change between bounded Turns. The Run controller owns lifecycle and admission.
SpecialistA profile-specific solving invocation: web, pwn, crypto, rev, forensics, stego, OSINT, AI or misc. It is reachable from every difficulty/Tier; evidence decides whether admission is worthwhile.
Recovery AgentA fresh bounded invocation for a novel operational fault. It is not a failed-solve fallback. Whole-Run faults value wall time; an isolated noncritical Lane fault may value capacity more.

Capacity governor

Always uncertain. Combine the published planning range with account/rateLimits/read fields such as usedPercent and resetsAt, then subtract a measured Recovery-and-tail reserve. Shared window movement is observed, never assigned as an invented exact per-Turn debit.

If telemetry is absent, use the conservative published band plus tighter admission. An explicit platform exhaustion response enters Quota wait. Capacity changes future admission, never silently downgrades an active Turn.

Luna's API and published-message advantage strongly prioritises it for comparison. Effort-specific subscription cost remains unpublished, so useful local outcomes and observed shared-limit movement still decide promotion.

Effort and multi-Turn rule

Difficulty sets the initial comparison band; trusted evidence and verified progress govern continuation. Specialists remain reachable at every difficulty/Tier. A trivial fixture can compare overhead but cannot disqualify high/max for a hard Challenge.

A Checkpoint may justify another Turn at the same or higher effort. Repetition without new verified progress weakens continuation. Model-authored confidence alone never escalates.

Once a Turn begins, requested model and effort freeze. A persistent Solve Lead keeps one model for its Attempt while effort may change between Turns. A different model receives a fresh Specialist invocation or later Attempt.

Evidence record and repetition rule

Calibration isolates one cell at a time. A paired pilot first estimates within-cell variance by authorized workload family and seed. Before confirmatory Runs, the evaluator predeclares repetitions, stopping rules and exclusions from that variance; it never stops because a preferred model happens to lead.

Every Turn records requested alias/model/effort, catalog family and snapshot, effective family and snapshot when reported, Run/Attempt/Turn and workload identity, outcome and Checkpoint provenance, queue/start/finish time, calls, uncached-input/cached-input/output/reasoning/unknown tokens, shared-limit snapshots before and after, and the measured Recovery reserve. Production records the same fields; it does not attribute shared-window movement as an exact Turn debit.

Each cell is candidate, Gate-approved, excluded or unknown. A material catalog or effective-identity change moves a previously tested cell to needs recheck; only matched evidence may promote it again.
